# 人生グラフ

人生の出来事と、そのときの実感の上下を一本の線で記録・共有する静的Webアプリです。

## ローカル起動

```bash
npm install
npm run dev
```

## ビルド

```bash
npm run build
```

生成物は `dist` に出力されます。Cloudflare Pagesではビルドコマンドを `npm run build`、出力ディレクトリを `dist` に設定してください。

## データについて

- 編集データとテーマ設定はブラウザ内に保存されます。
- 共有リンクには圧縮したデータが含まれ、外部DBやAPIは使用しません。
- JSONでバックアップし、PNGで画像として保存できます。
